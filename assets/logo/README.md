# xis logo

These files are the logo of xis. Use the SVG files where you can. Use the PNG files where a tool needs a bitmap.

| File | Use |
| --- | --- |
| `svg/xis-lockup-light.svg` | Mark and name on a light background, for example the README in a light theme. |
| `svg/xis-lockup-dark.svg` | Mark and name on the dark background `#0E1116`, for example the README in a dark theme. |
| `svg/xis-lockup-light-accent.svg` | Orange mark and dark name on a light background. |
| `svg/xis-mark-*.svg` | The mark only, in ink, white or orange. |
| `svg/xis-wordmark-*.svg` | The name only, in ink or white. |
| `svg/xis-app-icon.svg`, `png/xis-app-icon-*.png` | The rounded square icon, for example an avatar or a package icon. |
| `svg/xis-favicon.svg`, `png/xis-favicon-*.png` | A small icon for a web page. |
| `png/xis-lockup-dark-1200.png` | The social preview image of the GitHub repository. |

The colors are:

| Name | Value |
| --- | --- |
| Accent (orange) | `#F5A524` |
| Ink | `#0E1116` |
| Paper | `#F4F2EE` |

The review UI uses the accent color for `∂ xis` in its header.

The name is set in JetBrains Mono and converted to outlines, so the files need no font. The SIL Open Font License 1.1 applies to the font. See `JetBrainsMono-LICENSE.txt`.
